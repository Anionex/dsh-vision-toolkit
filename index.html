One runtime, explicit tools

Visual engineering without a universal action switch.

Each capability has its own schema and structured result. The versioned Skill activates them for one Agent, while health and version administration stay in Web Settings instead of model context.

01

Understand and locate

Glance, OCR, grounding, and detection return text plus original-image pixel boxes.

02

Recover and extract

Crop, SVG trace, foreground extraction, and dominant-color analysis produce reusable geometry and assets.

03

Verify the pixels

Local HTML rendering and ranked pixel diff close the reference-to-implementation loop.

04

Ship real Artifacts

Images, SVG, Markdown, and reports carry stable descriptors for preview, download, or local open.

05

Protect credentials

DSH Credentials, path fencing, hard deadlines, redacted errors, and explicit endpoints keep data handling visible.

06

Run Web or Headless

Web adds cards and Settings; Headless receives the same complete tool semantics and structured results.

Quick start

Install one checkout into the profiles you use.

Requires DeepSeek Harness, Python 3.11+, and pnpm available to dsh plugin. Restart a running Web profile, then configure the visual endpoint and DSH Credential in Settings.

Full installation and security guide 
git clone https://github.com/dsh-external/dsh-vision-toolkit.git
PLUGIN="$PWD/dsh-vision-toolkit"

dsh plugin --profile web add "$PLUGIN"
dsh plugin --profile headless add "$PLUGIN"

dsh --profile web --dump-config | grep vision-toolkit
